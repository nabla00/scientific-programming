# Scientific Programming Project

Course project site, published with GitHub Pages.

## Publish
1. Create a GitHub repository and upload everything in this folder (keep `index.html` at the top level).
2. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
3. After a minute or two, the site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

## Edit
Replace the placeholder text (YOUR PROJECT TITLE, Your Name, example items) in the five `.html` files, and drop your real files in the matching folders.

## Code page
Zip each laboratory's Python project folder (for example `lab1.zip`) and put it in `code/`. Each entry in `code.html` links to its ZIP. On the Numerical Problems page, a problem's code link points to the entry with `code.html#lab1`.
